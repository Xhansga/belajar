Rekayasa Perangkat Lunak

Belajar membuat aplikasi dari nol: logika pemrograman, web, basis data, sampai aplikasi mobile dan kerja tim dengan Git. Materi disusun bertahap mengikuti Kurikulum Merdeka SMK (Fase E dan F), dengan proyek nyata di setiap tahap.

Alur belajar

Ikuti urutan ini supaya setiap materi punya dasar yang kuat.

Kelas X · Fase E

Dasar pemrograman dan web

Berpikir komputasional, algoritma, HTML, CSS, dan JavaScript untuk halaman web interaktif.

Kelas XI · Fase F

Backend dan data

Basis data MySQL, PHP, pemrograman berorientasi objek, dan aplikasi CRUD lengkap.

Kelas XII · Fase F

Aplikasi utuh dan kerja tim

Mobile app, REST API, Git, pengujian, proyek akhir, dan persiapan UKK.

Perangkat yang dipakai

Semua gratis dan bisa dipasang di laptop sekolah maupun pribadi.

Visual Studio CodeXAMPP / LaragonGit dan GitHubNode.jsFigmaPostmanAndroid Studio / Flutterdraw.io (UML dan ERD)

Modul pembelajaran

Buka tiap modul, lalu centang topik yang sudah kamu kuasai.

Penilaian dan proyek akhir

Portofoliomu adalah bukti terbaik kompetensimu.

Cara penilaian

  • Kognitif (25%): kuis konsep dan tes tertulis tiap modul.
  • Praktik (55%): tugas coding, code review, dan uji kompetensi.
  • Sikap kerja (20%): kerja tim, disiplin commit, dan dokumentasi.

Ide proyek akhir

  • Sistem informasi sekolah: absensi, nilai, dan pengumuman.
  • Aplikasi kasir (POS) untuk UMKM, versi web dan mobile.
  • Toko online dengan keranjang, pembayaran simulasi, dan dashboard admin.
  • Aplikasi mobile pelaporan masalah lingkungan dengan REST API.

Sertifikasi dan karier

Target yang bisa kamu kejar setelah menyelesaikan materi.

Sertifikasi dan portofolio

  • Sertifikasi BNSP: Junior Web Programmer atau Junior Mobile Programmer
  • Kelas dan sertifikat Dicoding atau freeCodeCamp
  • Portofolio di GitHub dengan minimal 3 proyek utuh
  • Profil LinkedIn dan situs portofolio pribadi

Peluang kerja

  • Web developer (frontend, backend, atau fullstack)
  • Mobile developer
  • QA tester dan technical support
  • Freelancer, atau lanjut kuliah Informatika dan Sistem Informasi
